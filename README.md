# web-components
PATh Web Components

View all components here: https://path-cc.io/web-components

## Install

This package updates frequently, it isn't a bad idea to bind your `dev` script to also update this package

```shell
pnpm add @chtc/web-components
```

## Creating new components

This repo uses [pnpm](https://pnpm.io). Install dependencies with:

```shell
pnpm install
```

### Running the dev environment

```shell
pnpm storybook
```
